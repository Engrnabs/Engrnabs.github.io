Annual SEO Report Builder

AI Schema Markup Generator

Webhook-triggered by a Google Apps Script menu, it scrapes page HTML for queued URLs, sends the content to Claude AI to generate JSON-LD schema markup, creates a Google Doc per page with the result, and updates the Schema Queue sheet status to "Awaiting Review."

n8n Schema

AI Meta Title & Description Generator

Form-triggered workflow that reads a client's page URLs from Google Sheets, fetches the top 2 GSC queries per page, scrapes the page HTML, and uses GPT-4o to generate SEO-optimized meta titles and descriptions written back to the sheet.

n8n Metadata

Tech Main Task Completion Cleaner

n8n Monday.com

Client Board Task Completion Cleaner

Monthly GA4 & GSC KPI Extractor

Runs on a monthly schedule, loops through all active clients in a config sheet, and pulls full-month GA4 metrics (sessions, conversions, landing pages) plus GSC data per client, appending each to dedicated tabs in the KPI Google Sheet.

n8n GA4 GSC

Weekly GA4 & GSC KPI Extractor

Fires every Tuesday at 12:01 AM Pacific, reads active clients from the Client Config tab, fetches the prior week's organic GA4 metrics and GSC performance per client, and appends the results to the GA4 Data and GSC Data tabs in the KPI sheet.

n8n GA4 GSC

Client Anniversary Discord Notifier
